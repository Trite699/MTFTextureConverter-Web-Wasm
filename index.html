MT Framework TEX ↔ PNG Converter

All conversion runs in a WebAssembly module (loading…) whose header, platform, swizzle and pixel-format logic is ported from Kuriimu2's plugin_mt_framework (3DS, Switch, PS3, PS4, PC, Mobile). Files never leave your browser.

Load binary .tex textures

Versions 0x9D and 0xA3 are shared by several platforms; Auto picks the first candidate Kuriimu2 offers (0x9D → PC, 0xA3 → 3DS). Each result has its own platform selector to re-decode. Wii (bres container) is not supported, as in Kuriimu2.

Target & PNG files

Unknown header fields (e.g. the bitfield's unk3, floats in the 0x66/0x70 headers) are written as 0. Block-compressed encoders are simple bounding-box encoders; ETC1, BC7, PVRTC and ATC are decode-only.

Core: mt_tex.cpp → mt_tex.wasm (clang, no libc). Ported from Kuriimu2 (plugin_mt_framework + Kanvas). BC7 / ATC / PVRTC block decoders from texture2ddecoder (MIT, © 2020 K0lb3). Decoding is cross-checked against texture2ddecoder for ETC1, DXT1/5, BC5, BC7 and PVRTC; platform swizzles and header layouts follow Kuriimu2's source but are not verified against real game files here.
